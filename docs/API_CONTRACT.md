# CoFlorist implementation contract

Express serves public/ at localhost:4317. Browser uses same-origin JSON; no API key in localStorage or responses. Root owns server/app.js, server/nebius.js, package.json. Frontend agent owns public/. State agent owns server/session.js + tests/session.test.js. Brain agent owns python/, scripts/setup-brain.*, server/brain-worker.js. Do not edit others' files.

GET /api/state returns {settings,session,brain,connection}. settings={model,apiConfigured,recipientName,recipientHistory,historyIsDemo,voiceEnabled,cameraMode,cameraUrl,cameraDeviceId,pythonExecutable,dataPath}; connection={status:'unconfigured'|'ready'|'error',model,lastError,latencyMs}; brain={status:'idle'|'starting'|'ready'|'running'|'error',mode:'unconfigured'|'flywire',lastResult:null|object,error:null|string}.

session={phase:'idle'|'planning'|'placing'|'paused'|'retry'|'approved'|'lifting'|'handover'|'awaiting_receipt'|'completed',paused:false,messages:[{id,role:'user'|'assistant',text,createdAt}],placements:[{color:'white'|'red'|'yellow'|'purple',position:'center'|'left'|'right',quantity:1,status:'pending'|'active'|'completed'}],activeTask:null|{id,color,position,quantity,method,status},events:[],failures:[],revision:0,busy:false}. Initial messages empty: human speaks first.

POST /api/settings accepts allowed settings + optional apiKey (memory only); response full state. POST /api/connect tests saved Nebius key via real NVIDIA Nemotron call; returns {ok,reply,...state}. GET /api/models returns {models:[id strings]}. POST /api/chat {text} returns {reply,...state}. Never silently use mock response on API failure; return HTTP error {error}. POST /api/action {action} returns full state. Allowed action names pause,resume,start,complete,fail,retry,lift,handover,received,release,reset. Each state mutation increments revision; reject stale async plans after pause/reset. POST /api/brain/start starts worker; POST /api/brain/run requests real neural run (returns result + state); GET /api/events is SSE 'state' event containing full state. UI can poll /api/state if SSE unavailable. Errors JSON {error}.

Model output contract: {reply:string,intent:'gift'|'arrange'|'pause'|'resume'|'approve'|'change'|'chat',placements:[{color,position,quantity}],shortExplanation:boolean}. Validate and gate approve until all placements completed. LLM never reports physical success; operator events do. pause takes immediate local path, no model wait.

Session module exports createSession(), applyIntent(session, modelResult), applyAction(session, action), addMessage(session,role,text). Mutate passed session; return session. Throw Error for invalid transitions. createSession includes above fields. Parent handles persistence. Brain manager exports class BrainWorker({pythonExecutable,dataPath,onChange}) with start(), run(payload), stop(), snapshot(); stdout JSONL request IDs. Native Python fixed spawn shell:false/windowsHide:true. Worker runs exact real FlyWire-derived data, explicit subset if used, never synthetic placeholder labelled real.

Main only: CoFlorist, tabs 메인/설정, tiny status, camera, conversation, mic/input, restrained stage indicator, compact operator controls + brain result visualization. Settings: password API key, model, connect; recipient and history (demo badge/toggle), camera device/url, voice controls, Python/data paths and real brain start/test, reset/export. No marketing paragraphs or extra nav.
