기준일: 2026-10-25 (한국시간). 전체 12단계 중 현재 4단계 진행 중. 1~3단계의 완료는 기획·설계 완료이며 실제 애플리케이션 구현 완료가 아니다.

**화면 설계**

- D4D에서 확인한 네이비 사이드바, 밝은 본문, 흰 카드, 단계 진행, 기록 구조를 참고한다.
- 가운데 큰 영역: 실제 꽃 작업 카메라와 현재 작업.
- 오른쪽: 한국어 음성 대화, 받아쓰기, 대기 요청.
- 아래: 실제 신경 계산에 연결할 시각화, 사용자가 요청한 설명 선호, 운영자 시작/완료/실패 버튼.
- 상단: AI 행동 제안 · 운영자 보조 실행 표시.
- 메시지: “당신이 고른 꽃, 함께 완성하는 순간”.
- 실제 로봇은 기존 조종 장치로 사람이 제어한다. 대시보드 대기 요청은 실제 모터를 직접 정지시키는 기능이 아니다.

**고정 기술 구조**

브라우저(한국어 음성·대시보드) → Express → Nebius Token Factory의 Nemotron(언어 의도·응답).
Express → node:child_process.spawn → Python/Brian2(실제 FlyWire 신경 계산).
별도 행동 정책 + SQLite 경험 기록 → 작업 제안 → 운영자 수동 조종 → 결과 입력.

stdin/stdout은 JSONL, stderr는 로그에 사용한다. FlyWire 뉴런 ID는 Node/API/DB에서 문자열로 다룬다. Python 작업자는 한 개와 작업 큐 하나로 시작한다. 실제 뇌 계산 시간과 생물학적 시뮬레이션 시간을 구분한다. 신경 활동에서 꽃 작업으로의 연결 규칙은 사람이 설계한 공학적 인터페이스이며 초파리의 감정·사회인지 재현이라는 주장을 하지 않는다.

**실행 완료 기준**

- Nebius/NVIDIA: 실제 런타임 호출 성공, 사용 모델 식별과 호출 기록 확인.
- 한국어 음성: 실물 마이크·스피커로 입력/응답 확인. 텍스트 대체만으로 완료 처리하지 않음.
- 뇌 지도: 실제 연결 데이터를 사용한 계산 결과 확인. 목업 애니메이션만으로 완료 처리하지 않음.
- 운영자 수행: 실제 수동 조종과 완료/실패 입력이 기록에 일치.
- 대기 요청: 즉시 다음 작업 제안·대기열 보류. 실제 로봇은 운영자가 기존 조종 장치로 정지.
- 제출: 요구 링크·공개 라이선스·영어 안내·영상·접수 확인.
